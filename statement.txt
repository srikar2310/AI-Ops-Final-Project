Train a model on a small sample ~100000 games from the lichess database over a large range of rating games. Some of the games have evaluations in the database but some dont. We filter the games based on this and if there is any skew on the rating ranges for these evaluated games, we take some unevaluated games from the dataset so that this skew vanishes and evaluate them on the local stockfish engine. For evaluation we input the pgn file of the game and get the move evaluations from the local stockfish. We use these as the inputs to the trained model. The exact model is still not decided.
